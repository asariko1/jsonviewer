Frequently Asked Questions

What do "in:", "type:", and "has:" do in the search box?
in: restricts matches to a specific field, e.g. surfside in:locationTitle. Leaving the text off browses every value of that field. If the field is a block (object/array) rather than a single value, your search text is matched inside that block instead.

type: restricts matches to a specific JSON value kind (string/number/boolean/null/object/array) - useful for avoiding false positives like "20" matching inside an unrelated string when you only meant the number.

has:fieldName is a more readable alias for in:fieldName with no search text. All three work together and in every view, including Compare mode.

Is my data safe and private?
Yes. Everything runs entirely in your browser - parsing, searching, formatting. Nothing you paste or upload is ever sent anywhere.

Why does search need at least 3 characters?
A 1-2 character query can match an enormous number of places in a large file, which is slow to highlight and not very useful anyway. Field-scoped search (in:fieldName) is exempt from this, since it's already narrowed to one key.

Can I use this on large files?
Yes. Tree, Preview, and Collapsible only build the part of the tree you actually have expanded, so opening a large file stays fast rather than rendering the entire structure up front. Search works directly against the underlying data (not the rendered DOM), so it also stays fast, and caps at 500 matches to avoid an overly broad query grinding things to a halt.

Can I use this for sensitive data?
Since nothing leaves your browser, yes. Sessions are kept in local storage though, which anything else running on the same page's origin could in principle read - if that matters for your data, clear the session when you're done.

Can I work on more than one file at a time?
Yes, using the Sessions panel on the left. Each session remembers its own source text and is stored in your browser's local storage, so it's still there after you reload the page or close the browser.

What browsers are supported?
Any modern browser - Chrome, Firefox, Safari, or Edge.

Is this free?
Yes, no ads, no account, no server component at all.
